# src/features/audio/ — 「はー」検出(担当: D)

## 役割
マイクの音から「はー」(息を吐く音)を検出し、検出したことを知らせるフックを作る。

## 作るもの
`useHaaDetector` フック1つ。

```ts
const { start, stop, status, level } = useHaaDetector({
  onDetect: () => { /* 「はー」を検出したときに呼ぶ */ },
  muted: false, // trueの間は検出しない(他端末の音の回り込み対策)
});
```
- `status`: `"idle" | "listening" | "denied"`(マイク許可が拒否された場合は`denied`)
- `level`: 現在の音量(0〜1)。デバッグ表示用

## 実装の方針(この順で作る)
1. **マイクを取る**: `navigator.mediaDevices.getUserMedia({ audio: true })`(ボタンを押したときに開始。HTTPSかlocalhostが必要)
2. **音量を測る**: `AudioContext` + `AnalyserNode`で、音量(RMS)を毎フレーム計算する
3. **音量のしきい値**で判定: 一定の音量を**0.5〜2秒ほど続けて**超えたら「はー」とみなす → `onDetect()`
4. 連続発火を防ぐ: 検出後は`CONFIG.HAA_MUTE_MS`の間、再検出しない
5. 精度を上げたいときだけ: 周波数の「雑音っぽさ」(スペクトル平坦度)を条件に足す

まずは**手順3まで**で十分。しきい値は定数にして、会場で調整できるようにする。

## 守ること
- ファイル先頭に`"use client";`
- **音声は保存・送信しない**。端末の中で処理するだけ(プライバシー面で発表でも伝えられる)
- 終了時は`stream.getTracks().forEach(t => t.stop())`と`audioContext.close()`でマイクを解放する
- Web Speech API(音声認識)は使わない(「はー」は言葉として認識されない)
- 通信は触らない。`onDetect`を呼ぶだけ(リーダーが`fog`イベントの送信につなぐ)

## 動作確認
単体で動くテストページ(`/test/audio`など)を作り、音量バーと「検出!」の表示を出して、しきい値を調整する。タブレットの実機でも確認する。
