## 製品概要
Connect Windowは、離れて暮らす家族の天気を窓のような画面に映し、手書きメッセージを通じて自然とつながれることを目指したコミュニケーションアプリである。
利用者それぞれの端末に窓を模した画面を表示する。さらに、曇ったガラスを指でなぞることで、文字やイラストを描いて相手に届けることができる。メッセージは一定時間が経つと消え、既読表示も設けないため、気軽に利用できる。
特別な用事がないと連絡することがないという問題を互いに共通の天気の話という話題により親子のコミュニケーションハードルの低下を目指したアプリ。
### 背景(製品開発のきっかけ、課題等）
私は、遠距離に住む知り合いと話す機会がよくある。あるとき、相手が東京、私が金沢にいる状況で、相手が「10月なのにまだ暑いよ」と話していたのに対し、私は「こっちは寒いよ」と返した。同じ日本でも、住んでいる場所が違うだけで気温に大きな違いがあることに驚き、相手の天気や気温を知ることができる窓があれば面白いのではないかと思った。

その後、家族にJPHacksに参加することを伝えた際、「そっちは雨だから気をつけてね」というメッセージをもらった。この経験から、普段はあまり連絡を取らない家族とも、天気の話なら自然に会話ができ、コミュニケーションのきっかけになるのではないかと気づいた。

そこで、最初に思いついた「相手の天気や気温を知ることができる窓」に、手書きでメッセージを送る仕組みを組み合わせれば、普段は連絡するきっかけが少ない家族とも自然につながれるのではないかと考え、Connect Windowを発案した。
### 製品説明（具体的な製品の説明）
Connect Windowは、離れた場所にいる2人の端末を接続し、お互いの地域の天気や景色を共有できる窓型のコミュニケーションアプリである。

画面には、設定した相手の地域の天気が窓の外の景色のように表示される。また、画面に「はぁ～」と息を吹きかけるとガラスが曇る演出を取り入れ、その曇った部分を指でなぞることで、手書きの文字やイラストを相手に届けられる。送信したメッセージは相手側の窓に表示され、一定時間が経過すると自然に消える。
さらに、既読表示を設けないことで、相手の反応を気にしすぎず、自分のタイミングで利用できるようにする。

例えば、相手の地域が雨であることに気づいたとき、曇ったガラスに「雨、大丈夫？」と書いて送ることができる。受け取った側は、手書きのメッセージから相手の温かみや気遣いを感じたり、気が向いたときに返事やイラストを描いたりできる。

このように、天気や景色を日常的に共有し、手書きメッセージを送り合うことで、特別な用事や話題がなくても、離れて暮らす家族や大切な人と自然につながれるアプリである。
### 特長
#### 1. 特長1天気の話を通じた親子の自然なつながり
離れた場所にいる相手の地域の天気を窓のような画面に表示する。お互いの天気の違いを楽しみながら、相手の状況を知ることができる。天気を共通の話題とすることで、特別な用事がなくても自然に会話が生まれ、親子のコミュニケーションのきっかけをつくる。
#### 2. 特長2 曇ったガラスに手書きで伝える
画面に「はぁ〜」と息を吹きかけるとガラスが曇り、その部分を指でなぞることで、文字やイラストを描いて相手に届けられる。キーボードで入力する文章とは違い、手書きならではの個性や温かさを伝えられる。例えば、母親がメッセージの最後にかわいいうさぎの顔を描くなど、ちょっとしたイラストでも親しみや愛情を伝えられる。
#### 3. 特長3返信のプレッシャーが少ない設計
既存のメッセージアプリでは、既読をつけると返信しなければならないと感じることがある。実際に私も、非常に疲れているときに親からのメッセージが来ていることがわかっていながら返信できなかったことがあった。
こうした経験から、Connect Windowでは既読表示を設けず、メッセージも一定時間が経つと霜のように自然に消える仕組みにした。すぐに返信する必要がないため、相手の反応を気にしすぎず、互いに自分のペースで気軽に利用できる。
### 解決出来ること
離れて暮らす家族は、連絡するきっかけがなかったり、何を話せばよいか分からなかったりして、連絡を取る機会が少なくなりがちである。Connect Windowでは、相手の地域の天気をきっかけに、手書きのメッセージで「雨、大丈夫？」など、ちょっとした言葉を気軽に送ることができる。特別な用事がなくても自然に連絡を取れるようにすることで、親子間のコミュニケーションのハードルを下げる事ができる。
### 今後の展望
今後は、天気や気温に応じた窓の演出をよりリアルにし、水滴などの表現を取り入れることで、相手が暮らす地域の様子をより身近に感じられるようにしたい。また、手書きメッセージの描画や共有機能を改善し、曇ったガラスに直接文字を書いているような自然な操作感を実現することで、より直感的で楽しい体験を目指す。

さらに、季節のイベントを取り入れ、会話のきっかけを増やしたい。例えば、「春になったね。そっちは桜が咲いた？」といったやり取りができるようにする。こうした会話を通じて、普段は何気なく通っている道でも、「ここにも桜が咲いていたんだ」と気づくきっかけになり、日常が少し豊かになると考えている。

将来的には、離れて暮らす家族や友人など、大切な人と日常的につながるための新しい選択肢となるアプリへと発展させたい。
