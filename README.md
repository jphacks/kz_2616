# Connect Window

  [![Connect Window デモ動画](https://jphacks.com/wp-content/uploads/2026/07/IMG
  _5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

  ## 製品概要
  Connect Windowは、離れて暮らす家族の天気を窓のような画面に映し、手書きメッセー
  ジを通じて自然につながることを目指したコミュニケーションアプリです。
  利用者それぞれの端末に窓を模した画面を表示します。曇ったガラスを指でなぞると、
  文字やイラストを描いて相手に届けることができます。メッセージは一定時間が経つと
  消え、既読表示もないため、気軽に利用できます。
  特別な用事がないと連絡しない、という問題に対し、天気という共通の話題で親子のコ
  ミュニケーションのハードルを下げることを目指したアプリです。

  ### 背景（製品開発のきっかけ、課題など）
  私は、遠距離に住む知り合いと話す機会がよくあります。あるとき、相手が東京、私が
  金沢にいる状況で、相手が「10月なのにまだ暑いよ」と話していたのに対し、私は「こ
  っちは寒いよ」と返しました。同じ日本でも、住んでいる場所が違うだけで気温に大き
  な違いがあることに驚き、相手の天気や気温を知ることができる窓があれば面白いので
  はないかと思いました。

  その後、家族にJPHACKSに参加することを伝えた際、「そっちは雨だから気をつけてね
  」というメッセージをもらいました。この経験から、普段はあまり連絡を取らない家族
  とも、天気の話なら自然に会話ができ、コミュニケーションのきっかけになるのではな
  いかと気づきました。

  そこで、最初に思いついた「相手の天気や気温を知ることができる窓」に、手書きでメ
  ッセージを送る仕組みを組み合わせれば、普段は連絡するきっかけが少ない家族とも自
  然につながれるのではないかと考え、Connect Windowを発案しました。

  ### 製品説明（具体的な製品の説明）
  Connect Windowは、離れた場所にいる2人の端末を接続し、お互いの地域の天気を共有
  できる窓型のコミュニケーションアプリです。

  画面には、相手の地域の天気が窓の外の景色のように表示されます。また、窓に「はぁ
  〜」と息を吹きかけるとガラスが曇る演出を取り入れ、その曇った部分を指でなぞるこ
  とで、手書きの文字やイラストを相手に届けられます。送信したメッセージは相手側の
  窓に表示され、一定時間が経過すると自然に消えます。
  さらに、既読表示を設けないことで、相手の反応を気にしすぎず、自分のタイミングで
  利用できるようにしています。

  例えば、相手の地域が雨であることに気づいたとき、曇ったガラスに「雨、大丈夫？」
  と書いて送ることができます。受け取った側は、手書きのメッセージから相手の温かみ
  や気遣いを感じたり、気が向いたときに返事やイラストを描いたりできます。

  このように、天気を日常的に共有し、手書きメッセージを送り合うことで、特別な用事
  や話題がなくても、離れて暮らす家族や大切な人と自然につながれます。

  ### 特長
  #### 1. 天気の話を通じた親子の自然なつながり
  離れた場所にいる相手の地域の天気を、窓のような画面に表示します。お互いの天気の
  違いを楽しみながら、相手の状況を知ることができます。天気を共通の話題にすること
  で、特別な用事がなくても自然に会話が生まれ、親子のコミュニケーションのきっかけ
  をつくります。

  #### 2. 曇ったガラスに手書きで伝える
  窓に「はぁ〜」と息を吹きかけるとガラスが曇り、その部分を指でなぞることで、文字
  やイラストを描いて相手に届けられます。キーボードで入力する文章とは違い、手書き
  ならではの個性や温かさを伝えられます。例えば、母親がメッセージの最後にかわいい
  うさぎの顔を描くなど、ちょっとしたイラストでも親しみや愛情を伝えられます。

  #### 3. 返信のプレッシャーが少ない設計
  既存のメッセージアプリでは、既読をつけると返信しなければならないと感じることが
  あります。実際に私も、非常に疲れているときに親からのメッセージに気づいていなが
  ら、返信できなかったことがありました。
  こうした経験から、Connect Windowでは既読表示を設けず、メッセージも一定時間が経
  つと霜が消えるように自然に消える仕組みにしました。すぐに返信する必要がないため
  、相手の反応を気にしすぎず、互いに自分のペースで気軽に利用できます。

  ### 解決できること
  離れて暮らす家族は、連絡するきっかけがなかったり、何を話せばよいか分からなかっ
  たりして、連絡を取る機会が少なくなりがちです。Connect Windowでは、相手の地域の
  天気をきっかけに、手書きのメッセージで「雨、大丈夫？」など、ちょっとした言葉を
  気軽に送ることができます。特別な用事がなくても自然に連絡を取れるようにすること
  で、親子間のコミュニケーションのハードルを下げることができます。

  ### 今後の展望
  母から意見を聞いたところ、「忙しい朝は、メッセージが届いていても気づきにくい」
  と言われました。そこで今後は、相手がメッセージに気づきやすくなる仕組みも実装し
  たいと考えています。

  さらに、季節のイベントを取り入れ、会話のきっかけを増やしたいです。例えば、「春
  になったね。そっちは桜が咲いた？」といったやり取りができるようにします。こうし
  た会話を通じて、普段は何気なく通っている道でも、「ここにも桜が咲いていたんだ」
  と気づくきっかけになり、日常が少し豊かになると考えています。

  将来的には、離れて暮らす家族や友人など、大切な人と日常的につながるための新しい
  選択肢となるアプリへと発展させたいと考えています。

  ### 注力したこと（こだわり等）
  * 特にこだわったのは、「はぁ〜」と息を吹きかけるとガラスが曇る機能です。息を検
  出する感度の調整が難しく、思うように反応しないことも多くありました。しかし、Co
  nnect Windowならではの特徴的な機能であるため、高い品質で実装したいと考え、何度
  も調整を重ねました。
  * 天気の背景の表現にこだわりました。日の出・日没の前後では、昼・夕焼け・夜の配
  色を少しずつ混ぜて切り替え、天気が変わるときも約1.5秒かけて色を移し替えるよう
  にしました。また、ガラスを拭く速さに応じて線の太さが変わるようにし、息のあとに
  なぞった場所から水滴が垂れて、相手の画面にも同じ形で表示されるようにしました。

  ## 開発技術
  ### 活用した技術
  #### API・データ
  * **Open-Meteo API**：天気コード、日の出・日没の取得（APIキーは不要）
  * **Supabase Realtime（Broadcast・Presence）**：筆跡・息・水滴・天気の送受信と
  、2人までの定員管理
  * **Geolocation API**：自分の地域の天気を取得するための位置情報の取得

  #### フレームワーク・ライブラリ・モジュール
  * **Next.js（App Router）・React・TypeScript**：Webアプリの基盤
  * **PixiJS**：雨・雪・雲などの天気の粒子表現
  * **perfect-freehand**：手書きの線の描画
  * **Web Audio API（AnalyserNode）**：マイクで「はぁ〜」の息を検出
  * **Zod**：受信したデータの検証
  * **Zustand**：設定値・接続状態・相手の天気の管理
  * **Vitest・Playwright**：単体テストとE2Eテスト
  * **Vercel・GitHub Actions**：本番デプロイ（mainへのマージで自動デプロイ）

  #### デバイス
  * **タブレット（iPad）・PC（Mac）**：窓を表示する端末。1台で使うことも、2台で
  接続して使うこともできます
  * **マイク**：息の検出に使用します（音声は端末の中だけで処理し、保存・送信はし
  ません）
  * **画面の点灯（Screen Wake Lock API）・全画面表示（Fullscreen API）**：窓を開
  いている間は画面が消えないようにし、全画面表示にも対応しています

  ### 独自技術
  #### ハッカソンで開発した独自機能・技術
* 息の検出：マイクの音量と音のノイズ感の両方で「はぁ〜」の息を判定し、感度の
     段階調整と再反応の抑制を行う。
* 曇りの表現：拭く速さで線の太さが変わり、フェードの途中でも拭いた跡が消えな
     いように曇りを合成する。
* 水滴の共有：なぞった場所から垂れる水滴を、筆跡と同じ時刻つきの点列で送り、
     相手の画面で同じ速さで再生する。
* 空の表現：日の出・日没の前後で昼・夕焼け・夜の配色を連続的に混ぜ、相手には
     天気の種類と日の出・日没だけを送る。
* 合言葉の部屋：合言葉からハッシュしたチャンネル名で 2 人を結び、3
     人目以降は入室させない。
