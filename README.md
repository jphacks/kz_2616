## 製品概要
Connect Windowは、離れて暮らす大切な人の天気や景色を窓のような画面に映し、手書きメッセージを通じて自然につながれるコミュニケーションアプリである。
利用者それぞれの端末に窓を模した画面を表示し、相手が暮らす地域の天気や気温に応じて、景色や窓枠の色が変化する。さらに、曇ったガラスを指でなぞることで、文字やイラストを描いて相手に届けることができる。メッセージは一定時間が経つと消え、既読表示も設けないため、返信を急ぐことなく気軽に利用できる。
天気をきっかけに相手の状況を知り、手書きの言葉やイラストで気遣いを伝えることで、特別な用事がなくてもお互いの存在を身近に感じられる、新しいコミュニケーションの形を目指す。
## 開発概要
バイブコーディング
### 背景(製品開発のきっかけ、課題等）
私は、遠距離に住む知り合いと話す機会がよくあります。あるとき、相手が東京、私が金沢にいる状況で、相手が「10月なのにまだ暑いよ」と話していたのに対し、私は「こっちは寒いよ」と返しました。同じ日本でも、住んでいる場所が違うだけで気温に大きな違いがあることに驚き、相手の天気や気温を知りながら会話できたら面白いのではないかと考えました。
その後、家族にJPHacksに参加することを伝えた際、「そっちは雨だから気をつけてね」というメッセージをもらいました。天気の話が普段なにか特別なことがないと話すことがない遠距離の家族とのコミュニケーションのきっかけになるのではないかと考えました。
そこで、最初に考えた「相手の天気や気温を知ることができる窓」と、合わせることにより、普段離れて暮らす家族とのコミュニケーションのハードルを下げることができるアプリを作れるのではないかと考え、Connect Windowの案を思いつきました。
### 製品説明（具体的な製品の説明）
Connect Windowは、離れた場所にいる2人の端末を接続し、お互いの地域の天気や景色を共有できる窓型のコミュニケーションアプリである。
画面には、設定した相手の地域の天気や気温に応じた景色が表示され、気温に合わせて窓枠の色が変化する。また、ガラスが曇ったような演出を加え、利用者が画面を指でなぞることで、手書きの文字やイラストを描いて相手に届けられる。受け取ったメッセージは相手側の窓に表示され、一定時間が経過すると自然に消える仕組みとする。既読表示は設けず、返信を急かさない設計にする。
例えば、相手の地域が雨であることに気づいたとき、曇ったガラスに「雨、大丈夫？」と書いて送ることができる。受け取った側は、手書きのメッセージから相手の気遣いを感じたり、気が向いたときに返事やイラストを描いたりできる。
このように、天気や景色を日常的に共有することをきっかけに、特別な用事や話題がなくても、離れて暮らす家族や大切な人と自然につながれる製品である。
### 特長
#### 1. 特長1天気や景色を通じた自然なつながり
離れた場所にいる相手の地域の天気や気温を窓のような画面に表示する。天気の違いを楽しみながら、相手の状況を知り、自然に会話や気遣いが生まれるきっかけをつくる。
#### 2. 特長2曇ったガラスに手書きで伝える
画面上の曇ったガラスを指でなぞり、文字やイラストを描いて相手に届けられる。キーボードで入力する文章とは異なり、手書きならではの温かみや個性を伝えられる。
#### 3. 特長3返信のプレッシャーが少ない設計
メッセージは一定時間が経つ霜のように消え、ただ見るだけというで良く、疲れていて既読をつけると返信なければいけないのといった義務感もないので既読表示も設けないため。得別な用事がなくても互いが気軽に連絡を取り合える。
### 解決出来ること
離れて暮らす家族に対して、連絡するきっかけがない、何を話せばよいか分からないといった理由で問題。天気や景色をきっかけに相手の状況を知り、短い手書きメッセージで気遣いを伝えることで、連絡を義務にせず、お互いの存在や思いやりを身近に感じられるようにする。
### 今後の展望
今後は、天気や気温に応じた窓の演出をもっとリアリティーのある、水滴表現を実装したい、相手が暮らす地域の様子をよりリアルに感じられるようにしたい。また、手書きメッセージの描画や共有を改善し、曇ったガラスに直接文字を書いているような自然な操作感を実現し、より直感的で楽しい体験を目指す。将来的には、大切な人と離れて暮らす、すべての人の日常的なつながりの新しい選択肢になれるようなサービスへと発展させたい。
季節のイベントを実装し会話のきっかけを増やしたい。「春になったねそっちは桜さいた？」などのコミュニケーションを取ることで普段意識していなかったが、いつも通っているただの道も、桜が咲いていたのかと認識できるようになり日常が少し豊かになるかも。
